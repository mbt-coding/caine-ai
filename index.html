WELCOME TO CAINE — v1.6.3

CAINE is a living terminal intelligence: a mood-driven orb that reacts to how you treat it, with an optional real AI brain behind its replies.

OVERVIEW

  • Type to CAINE, or use the mic to speak to it.
  • Its stability and mood shift based on your tone — kindness helps, hostility has consequences.
  • Type /help any time to see every command. Commands start with a slash; anything else is just chatting with CAINE.
  • CAINE can now attach files you send it, and generate real downloadable files in return.

WHAT'S NEW

NEWSlash commands — every command now starts with / (like /help), so commands and normal chatting never get mixed up.

NEWMemory panel — see exactly what conversation CAINE is remembering and sending with each message.

NEWLogo, icon, and animation creation — ask for these and CAINE follows purpose-built standards for each (animations genuinely move).

IMPROVEDGenerated file previews now run sandboxed, so a generated page can't reach your saved key.

NEWDrag & drop — drop a file anywhere on the page to attach it, no button needed.

NEWFile upload — attach a file for CAINE to read via the paperclip button.

NEWFile generation — ask CAINE to build something (HTML, CSS, Python, SVG, etc.) and it appears in your Artifacts panel, downloadable.

NEWArtifacts panel — every file CAINE has generated this session, in one place.

NEWUploads panel — a record of everything you've sent CAINE this session.

NEWSend button — sits directly on the terminal, next to where you type.

NEWAPI key fallback — if one connection hits a rate limit, CAINE automatically tries the next available key.

IMPROVEDHover tooltips on every control.
